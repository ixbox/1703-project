# 車両仕様

## 基本仕様

- **型式**: 1703（蒸気機関車型）
- **ゲージ**: 5インチ（軌間127mm）
- **用途**: 展示走行（乗車は想定しない）
- **駆動方式**: 電動モーター駆動
- **製作**: 約30年前、祖父による手作り

## 駆動機構

### ウォームギア

**仕様**:
- ギア比: **1:41**（モーター1回転で駆動輪1/41回転）
- 製作: 手作り
- 材質: 不明（実機から確認）

**特性**:
- **自己保持性（セルフロック）**: 駆動輪からモーターへの逆回転が困難
- **減速比が大きい**: トルクを増大、速度を減少
- **効率が低い**: 平ギアと比較して伝達効率が低い（30-90%程度）
- **バックラッシュあり**: 手作りのため遊びが存在

### 駆動輪

**仕様**:
- 直径: **89.5mm**
- 円周: 約**281mm**
- 材質: 不明（実機から確認）

### モーター

**型式**: RS-540SH（タミヤ製ラジコン用モーター）

**スペック（概算）**:
- 定格電圧: 7.2V
- 無負荷回転数: 約20,000 rpm（7.2V時）
- 無負荷電流: 約0.5-1A
- 最大効率時: 約3-5A程度
- ストール電流: 20A以上

**動作確認**:
- 5V印加で回転確認済み（低トルクだが動作可能）

## 速度計算（理論値）

### 計算条件
- モーター回転数: 20,000 rpm（7.2V、無負荷時）
- ギア比: 1:41
- 駆動輪円周: 281mm

### 計算結果
```
駆動輪回転数 = 20,000 / 41 ≒ 488 rpm ≒ 8.1 rps
移動速度 = 8.1 rps × 281mm ≒ 2,277 mm/s ≒ 2.3 m/s
時速換算 = 2.3 m/s × 3.6 ≒ 8.3 km/h
```

**理論最高速度**: 約**2.3 m/s**（時速8.3 km）

**注意**:
- 実際は負荷、ギア効率、摩擦により大幅に低下
- PWM dutyと速度の関係は実測して確認が必要
