## モータードライバ: BTS7960

### 仕様
- 最大電流: 43A
- PWM入力: RPWM, LPWM（独立制御）
- イネーブル: R_EN, L_EN（Arduino制御）
- 電流センス: R_IS, L_IS
- ロジック電源: 5V
- モーター電源: 7.2V

### 配線仕様

```
BTS7960          Arduino UNO R3/Nano
----------------------------------------
RPWM       →     D9  (Timer1 PWM, OCR1A)
LPWM       →     D10 (Timer1 PWM, OCR1B)
R_EN       →     D11 (Digital Out)
L_EN       →     D12 (Digital Out)
R_IS       →     A0  (Analog In)
L_IS       →     A1  (Analog In)
VCC        →     5V
GND        →     GND
B+         →     7.2V (Battery+)
B-         →     Battery-
M+         →     Motor+
M-         →     Motor-
```

### EN端子制御方式の採用理由
- ハードウェア的にモーター回路を切断可能（安全性向上）
- 緊急停止時の確実な動作保証
- 方向転換時の誤動作防止

## キャラクタLCD: 1602

### 仕様
- 表示: 16文字×2行
- コントローラ: HD44780互換
- 動作電圧: 5V
- 接続方式: 4ビットパラレル

### 配線仕様

```
1602 LCD         Arduino UNO R3/Nano
----------------------------------------
VSS        →     GND
VDD        →     5V
V0         →     10kΩ可変抵抗（コントラスト調整）
RS         →     D2
RW         →     GND（書き込み専用）
E          →     D3
D4         →     D4
D5         →     D5
D6         →     D6
D7         →     D7
A (LED+)   →     5V（バックライト）
K (LED-)   →     GND
```

### 用途
- デバッグ用簡易表示
- 状態モニタリング（デューティ比、電流値など）

## 電流センサ

### BTS7960内蔵センサ（R_IS/L_IS）

**Phase 1で使用**:
- 電流比: 約1/8500
- 用途: 電流モニタリング
- 出力: アナログ電圧（Arduino ADCで読み取り）
- 測定対象: 各方向の電流を独立して計測可能

**接続**:
- R_IS → Arduino A0
- L_IS → Arduino A1

### ACS758LCB-050B（Phase 2以降で検討）

**仕様**:
- 測定範囲: ±50A
- 感度: 40mV/A
- 出力中点: 2.5V（VCC=5V時）
- 配置案: ローサイド
- 特徴: 絶縁型、双方向計測、高精度

**備考**: 
Phase 1では実装せず、より精密な電流計測が必要になった場合に追加検討。

## 電気回路図

### Phase 1の構成

```
[Battery+] → [Fuse] → [Main SW] → [BTS7960] → [Motor] → [Battery-]
                                        ↓
                                   R_IS, L_IS
                                        ↓
                                   Arduino ADC
```

### Phase 2での拡張案

```
[Battery+] → [Fuse] → [Main SW] → [BTS7960] → [Motor] → [ACS758] → [Battery-]
                                        ↓                      ↓
                                   R_IS, L_IS            Arduino ADC
                                        ↓
                                   Arduino ADC
```

## 筐体内配置

### 物理レイアウト（推定）

```
[バッテリー] → [ヒューズ] → [スイッチ]
                              ↓
                        [BTS7960]
                          M+  M-
                           ↓
                        [モーター]
                       （ウォームギア）
                           ↓
                        [駆動輪]
```

### 配置の考慮点
- BTS7960をモーターの近くに配置し、配線を短縮
- 発熱部品（BTS7960、モーター）は放熱を考慮して配置
- 実際の配置は既存の筐体構造と重量バランスを考慮して決定

## 配線材料

### 7.2V系（モーター駆動系）

**ケーブル**:
- カーオーディオ用 1.25sq（AWG16相当）
- 理由：
  - 調達が容易（カー用品店で入手可）
  - 許容電流: 約10-15A（十分な余裕）
  - 柔軟性があり車両内配線に適している

**コネクタ**:
- ギボシ端子（250型）
- ファストン端子（6.3mm）
- 理由：
  - 汎用性が高く入手容易
  - 工具不要で着脱可能（メンテナンス性向上）
  - 各種部品との接続が容易
  - 振動に対する信頼性

### 5V系（制御系）

**ケーブル**:
- 細線（AWG22-24程度）
- デュポンコネクタ、XHコネクタなど
- 信号線は個別に絶縁されたリボンケーブルも検討

### 配線の更新方針

**現状**:
- 既存配線は30年の経年劣化あり
- 全面的に更新予定

**流用可能部品**:
- モーターと制御盤間のU字ターミナル端子板（状態次第で流用可能）

## 保護回路

### ヒューズ
- 容量: 10A
- 配置: ハイサイド（Battery+側）
- 種類: ブレード型ヒューズ（カー用品）

### メインスイッチ
- 役割: キルスイッチ兼用
- 配置: ヒューズ直後
- 種類: トグルスイッチ

### 過電流保護
- ソフトウェアによる電流監視
- 閾値超過時の自動停止
- 閾値は実測により決定

## バッテリー

### Phase 1での選定

**タミヤ 7.2V NiMHバッテリー**:
- 電圧: 7.2V（公称）
- 容量: 未定（実際のバッテリーにより異なる）
- 理由：
  - RS-540SHの定格電圧に適合
  - 入手が容易
  - 充電器が一般的

### 旧バッテリー（交換）

- 種類: バイク用鉛蓄電池
- 状態: 電圧0.1V（使用不可）
- 配置: 荷重バランス用として残す（端子は絶縁）

## 制御系電源

### Arduino用電源

**Phase 0/1**:
- 5Vモバイルバッテリー
- USB給電またはVin端子給電

**理由**:
- 手軽に入手可能
- 安定した5V供給
- 容量が大きい

## Phase 2での追加（将来）

### UI MCU用電源
- ESP32用: 3.3V（内蔵レギュレータ or 外部レギュレータ）
- ディスプレイ用電源（使用デバイスにより異なる）

### レベルシフト
- UART通信用: TXS0108E, BSS138等の双方向レベルシフタ
- 5V（Arduino Nano）↔ 3.3V（ESP32）

## 実装時の注意事項

### 配線時
- モーター系と制御系の配線を分離（ノイズ対策）
- GNDは1点アースを推奨
- 電源ラインは太めに、信号線は細めに

### 組み立て時
- 発熱部品の放熱を確保
- 振動対策（ケーブルタイ、グロメット等）
- ショート防止（絶縁処理、配線経路の確認）

### デバッグ時
- テスターでの導通確認
- 電源投入前の目視確認
- 段階的な通電（制御系→モーター系）
