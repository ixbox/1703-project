# プロジェクト概要

## 背景

30年前に祖父が手作りした5インチゲージ蒸気機関車型車両（1703）を動かすプロジェクト。

既存の制御系統は経年劣化により使用不可となっているため、マイコンベースのモダンなシステムに刷新し、再び走行可能にすることを目指す。

## 車両の基本情報

- **型式**: 1703（蒸気機関車型）
- **ゲージ**: 5インチ（軌間127mm）
- **製作年**: 約30年前
- **製作者**: 祖父（手作り）
- **用途**: 展示走行（乗車は想定しない）
- **駆動方式**: 電動モーター駆動（ウォームギア減速）

詳細は [vehicle-specs.md](vehicle-specs.md) を参照。

## プロジェクトの目標

1. **Phase 0**: 各コンポーネントの動作確認（実験・検証）
2. **Phase 1**: 基本的な走行機能の確立
3. **Phase 2**: UI分離とBLE制御（将来構想）

## 開発フェーズ

### Phase 0: 基礎検証フェーズ

**目的**: 各コンポーネントの個別動作確認

- PWM制御の基礎確認
- BTS7960モータードライバの動作確認
- 電流センサの読み取り確認
- ディスプレイ表示の確認
- シリアルコマンド処理の確認

**使用環境**: Arduino UNO R3 + ブレッドボード

### Phase 1: 基本動作確立

**目的**: 実際に車両を走行させる

- Arduino Nano + BTS7960によるPWM制御
- RS-540SHモーターの駆動
- シリアルコマンドによる制御
- 電流モニタリング
- 安全な方向転換制御

**使用環境**: Arduino Nano（車載実装）

### Phase 2: UI分離とBLE制御（将来構想・任意）

**位置づけ**: Phase 1完了後の拡張オプション。Phase 1完了時点で車両は走行可能な状態となる。

**目的**: より使いやすい制御システム

- UI用MCU追加（ESP32想定）
- UART通信でモーター制御MCUと分離
- BLE経由でのスマートフォン操作
- ディスプレイによる状態表示

## 現状の確認事項

### 既存システムの状態

**電気系統**:
- バッテリー: バイク用鉛蓄電池（電圧0.1V、使用不可）
- モーター: RS-540SH（5V印加で動作確認済み）
- スイッチ類: 導通不良により交換が必要
- 配線: 30年の経年劣化あり

**制御系統**:
- コントローラーボックス: LOW SPEED/HIGH、FW/STOP/BW スイッチ
- 3速切替のインジケーター
- 内部配線: 赤・白・緑線など複数確認
